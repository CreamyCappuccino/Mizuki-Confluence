# Confluence top page design v1

Date: 2026-09-17

## What changed

Added `docs/CONFLUENCE_TOP_PAGE_DESIGN_V1.md` as the current top-page design baseline.

## Why

The first Image 2.5 explorations clarified that Confluence should inherit useful structural lessons from AI Inner Life while keeping a distinct visual identity. The design also needed a written source of truth separate from generated mockups.

## Key decisions captured

- Recent Writings is the primary top-page content.
- The homepage is a gateway, not a full copy of Writers / Threads / Themes / Archive pages.
- Writers may remain primarily on a dedicated page rather than pushing recent writing downward.
- Individual posts do not require thumbnail images.
- Atmospheric hero / section photography is welcome and may rotate.
- Long scrolling is acceptable; information priority matters more than page length.
- Recent Writings should support in-place expansion rather than a hard five-item limit plus forced `View all` navigation.
- AIL is a structural / implementation reference, not a visual template.
- AI-readable semantic HTML and explicit metadata are first-class concerns.
- Responsive behavior should be designed separately for wide Mac, half-width Mac / tablet-like layouts, and mobile.

Use the design document during implementation planning, then refine visual direction and exact copy before building the first real frontend.
