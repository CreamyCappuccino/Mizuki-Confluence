# Atmospheric assets — prototype v0.2

These images were cropped from the AI-generated Confluence UI concept
`人とaiが交わる静かな知の場所.png`, created earlier in the same design conversation.
The source is a 935 × 1683 image. No third-party stock photo was downloaded.

- `studio-window.webp`: source rectangle (365, 64, 935, 389); 570 × 325.
- `studio-afternoon.webp`: source rectangle (0, 1325, 600, 1570); 600 × 245.

Coordinates are left/top/right/bottom in source pixels. Encoded as WebP,
quality 84. Crops exclude interface headings and controls; physical book or
poster lettering inside the generated scene may remain.

These are intentionally **interim, medium-resolution assets**, not final
high-resolution photography. Replace them with dedicated images as the visual
direction settles. UI copy, buttons, navigation and article content remain
real HTML, never part of these photographs.

No external image URL is loaded. The two scene names are stable hooks for
future asset replacement; the reader changes scenes explicitly rather than
being subjected to a timed carousel.
